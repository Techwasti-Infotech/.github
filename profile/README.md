### 🌐 About TechWasti Infotech

**TechWasti Infotech Pvt. Ltd.** is an enterprise engineering and SaaS innovation powerhouse based in Pune, India. We specialize in designing fault-tolerant, high-concurrency distributed architectures, enterprise-grade cloud native platforms, and pioneering autonomous Generative AI & Model Context Protocol (MCP) agentic workflows.

Alongside core enterprise services, TechWasti incubates next-generation cloud infrastructure products and powers the **TechWasti Academy**—an open ecosystem democratizing advanced systems engineering knowledge worldwide.

| Platform | Domain | Overview |
| :--- | :--- | :--- |
| **StreamIQ** | *Event Streaming & Observability* | Centralized B2B SaaS platform for real-time Apache Kafka streaming pipeline telemetry, partition lag intelligence, and anomaly diagnostics. |

### 🌟 Open Source & Developer Utilities

We believe in paying engineering forward. Our team contributes open-source primitives and tools to solve complex production challenges:

- 🛡️ **[`go-resilience`](https://github.com/Techwasti-Infotech)** — High-efficiency resilience patterns for Golang (circuit breaker, rate limiter, jittered backoff retry, bulkhead).
- 📁 **[`go-file-utils`](https://github.com/Techwasti-Infotech)** — Zero-allocation streaming file processing, chunking, and memory-safe I/O helpers for Go microservices.
- 🧩 **[`dev-utils-VSCode-plugin`](https://github.com/Techwasti-Infotech)** — Productivity boosters for developers manipulating tokens, encoders, formatters, and network mocks directly inside VS Code.
- 📚 **[`TechWasti Academy Content`](https://techwasti.com)** — Open guides on system design, microservices communication, concurrency primitives, and clean code principles.
